# CareerPath AI

## Overview

CareerPath AI is a web-based career growth recommendation platform designed to help professionals and students evaluate their current skills, identify career gaps, and generate a structured roadmap toward their target roles.

The application provides promotion readiness analysis, salary estimation, skill gap assessment, career planning recommendations, and an interactive career assistant through a simple and user-friendly dashboard.

---

## Features

### User Profile Management
- User registration and login
- Profile creation and editing
- Career goal selection
- Experience tracking

### Career Analytics
- Promotion probability prediction
- Promotion readiness assessment
- Estimated salary range calculation
- Career growth insights

### Skill Assessment
- Current skill evaluation
- Skill proficiency tracking

- Structured monthly learning plan

### AI Career Assistant

- Career advice recommendations
- Skill improvement suggestions

### Data Visualization
- Promotion readiness gauge
- Skill radar chart
- Dashboard analytics
- Interactive performance metrics

## How to Run

1. Download or clone the repository.

```bash
git clone https://github.com/YOUR_USERNAME/careerpath-ai.git
```

2. Open the project folder.

3. Launch `index.html` in a web browser.

No additional installation or server setup is required.

1. Enter user details.

3. Add skills and proficiency levels.
4. Generate career insights.
5. Analyze promotion readiness.
